# 科学依据与表达边界 / Scientific scope

Twinverse帮助用户建立直观理解。每个场景都应说明它依据什么、计算了什么、哪些部分只是观察辅助。贡献者请保留这三层区别。

## 当前模型的边界

| 内容 | 已采用的依据/方式 | 不应由画面推断的结论 |
|---|---|---|
| 行星与主要天体 | 固定日期范围的JPL参考星历、IAU姿态参数及统一日期 | 无覆盖日期的精密预测、当前天气或任意尺度下的真实视直径 |
| 天然卫星 | 冻结目录与有限时段位置缓存，未知尺寸/缺测明确标记 | 目录永久完整、缓存之外仍有可靠轨迹，或灰色球体就是已知地貌 |
| 宇宙网与银河 | 程序化三维结构、理想化运动及可重播间距演示 | 实测星系分布、宇宙中心、真实宇宙年代或完整动力学 |
| 地球与地面夜空 | 历史地表/云合成图、参考星表、有限方向几何与作者地形 | 实时云层/天气、实地测绘、肉眼亮度或精密天象预报 |
| 海陆生态与城市 | 具名物种参考、作者动作/数量/场景与局部教学关系 | 野外种群测量、完整生态预测或真实城市交通建议 |
| 生命内部 | 局部参考结构和明确假设下的教学模型 | 活体扫描、医学/生理诊断或目标物种全部参数已标定 |

太阳系全景可以使用距离压缩和大小放大；物理近景及卫星同框采用统一长度比例，并可用方向标记辅助发现远处对象。界面的模式说明是理解比例的必要部分。

应用内部的“知识 / 依据与边界”提供对应主题来源。[资源与第三方署名](../../THIRD_PARTY_NOTICES.md)保存媒体和数据归属。

## 如何提交科学纠错

提供场景/主题、复现操作、目前呈现、建议更正及主要来源。区分：

1. **数据错误**：单位、坐标、周期、物种名称或引用不一致。
2. **模型局限**：超出目前有效日期、假设或简化范围，需要调整模型或说明。
3. **显示问题**：视觉放大、镜头或标签使用户容易产生错误理解。

优先给出机构资料、数据集或研究论文的具体章节/表格。不要用单幅生成图替代科学来源。改动说明、数据和画面应一致；暂时无法解决的限制要公开说明。

## English summary

The application combines reference data, finite models and authored visualization. Its cosmic web is illustrative; habitats and behavior are teaching scenes; maps and sky data are historical rather than live. Orbital data have finite validity intervals, and missing values must remain explicit. Science contributions should distinguish incorrect data, model limitations and misleading presentation, with primary references and reproducible steps.
